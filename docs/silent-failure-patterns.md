# 조용한 실패 5유형 — 에러 없이 멈추는 자동화를 탐지하기

> 운영 자동화의 실패는 대부분 **에러 메시지로 오지 않는다.**
> 아무 일도 일어나지 않는 형태로 오고, 아무 일도 일어나지 않았다는 사실은 아무도 모른다.

자동화를 늘릴수록 이 문제가 커진다. 사람이 하던 시절에는 "오늘 그거 안 했네"를 누군가 알아챘는데,
시스템에 넘긴 뒤에는 **돌고 있다고 가정**하기 때문이다.

실제로 겪은 사례들을 유형으로 정리하고, 각각에 대한 탐지 방법을 붙였다.

<br>

## 유형 1 — 스케줄러 무응답 (Dead Scheduler)

**증상** 스케줄에 등록된 작업이 실행되지 않는데, 실패 로그도 남지 않는다. 실행 자체가 시작되지 않았기 때문이다.
**원인 예** 스케줄 파일 확장자·플래그 변경 / 호스트 재부팅 후 미등록 / 실행 환경 PATH 미설정

**탐지**
```
❌  실패를 감시한다            → 실행이 없으면 실패도 없다
✅  마지막 성공 시각을 감시한다  → 기대 주기를 넘기면 알림
```
**하트비트 체크**를 도입한다. 작업이 성공할 때마다 타임스탬프를 남기고, **그 타임스탬프의 나이**를 별도 감시자가 본다.

> 🔴 감시자 자신이 같은 스케줄러 위에 있으면 함께 죽는다. 감시는 반드시 다른 실행 경로에 둔다.

<br>

## 유형 2 — 만료 (Expiry)

**증상** 어제까지 되던 연동이 오늘 갑자기 안 된다. 코드는 그대로다.
**원인 예** API 라이선스·인증서·FTP 자격증명의 유효기간 만료

**탐지**
```
만료일을 대장에 등록  →  만료 전 자동 통보  →  갱신 후 대장 갱신
```
핵심은 **만료일이 사람 머릿속이 아니라 시스템에 있는 것**이다.
만료는 예측 가능한 유일한 장애 유형이므로, 이걸 놓치는 건 설계 실패다.

<br>

## 유형 3 — 무증상 미수행 (Zero Output)

**증상** 시스템은 정상으로 보이고 에러도 없는데, **결과물이 0건**이다. 0건이 정상인지 이상인지 구분이 안 된다.
**원인 예** 선행 조건(번호대·쿼터·잔액)이 소진되어 처리 대상이 만들어지지 않음

**탐지**
```
❌  "실패하면 알린다"
✅  "정상이어도 처리 건수를 보고한다"  →  0건이 며칠 이어지면 이상
```
**"이상 없음"도 출력**해야 한다. 조용히 넘어가면 돌렸는지 안 돌렸는지 알 수 없다.
분모를 정직하게 만드는 것도 여기 포함된다 — 처리 대상이 아닌 건을 분리해야 0%가 무슨 뜻인지 알 수 있다.

<br>

## 유형 4 — 조용한 값 리셋 (Silent Reset)

**증상** 정상 절차를 밟았는데 값이 초기화된다. 아무 에러도 나지 않고, **의도한 값과 다른 값이 고객에게 보인다.**
**원인 예** 속성이 상위 객체가 아니라 하위 항목에 붙어 있어, 상위를 재생성하면 하위 속성이 기본값으로 돌아감

**탐지**
```
변경 작업 직후 자동 실행되는 검증을 상주화한다
— 사람이 기억해서 실행하는 체크리스트는 반드시 실패한다
```
트리거 기반으로 만든다. **"작업했으면 검사한다"가 아니라 "작업하면 검사가 돈다".**
그리고 결함을 발견해도 **자동으로 고치지 않는다** — 의도된 설정일 수 있으므로 먼저 보고한다.

<br>

## 유형 5 — 자기 손상 (Self-Corrupting Automation)

**증상** 복구 자동화가 반복 실행되면서 **스스로 새로운 손상을 만든다.**
**원인 예** 감싸기·정규화 로직이 멱등하지 않아, 실행할 때마다 중첩이 쌓임

**탐지**
```
같은 입력에 두 번 실행해서 두 번째 결과가 첫 번째와 같은지 본다  (멱등성 테스트)
손상 주입 테스트 — 일부러 망가뜨린 뒤 복구되는지 E2E 로 확인
```
자동 복구는 **멱등하지 않으면 만들지 않는 편이 낫다.** 최악의 경우가 여기에 있다.

<br>

## 탐지 설계 체크리스트

새 자동화를 배포하기 전 5개를 확인한다.

- [ ] 이게 **실행되지 않았다는 것**을 어떻게 알 수 있는가? (실패가 아니라 부재)
- [ ] 만료되는 자격증명·기한이 있는가? 대장에 등록했는가?
- [ ] 결과 0건이 정상인가 이상인가? 구분할 수 있는가?
- [ ] 이 작업이 건드리는 값이 다른 작업에 의해 초기화될 수 있는가?
- [ ] 두 번 실행해도 같은 결과인가? (멱등)
